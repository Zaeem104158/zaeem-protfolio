# Zaeem Ahmed — Portfolio

A modern, dark-themed portfolio website built with pure HTML, CSS & JavaScript. Fully static and GitHub Pages ready.

## 🚀 Quick Start

1. Clone this repo
2. Open `index.html` in your browser
3. That's it — no build tools needed!

## ✏️ Customize Your Content

All portfolio content lives in a single file: **`data.js`**

Edit this file to update:
- Your name, title, and bio
- Skills and proficiency levels
- Projects with descriptions and links
- Work experience timeline
- Education details
- Contact info and social links

## 📄 Resume

Replace `assets/resume.pdf` with your actual resume file. The download button in the navbar, hero section, and floating button will all link to it.

## 🌐 Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Under **Source**, select **Deploy from a branch**
4. Choose **main** branch and **/ (root)** folder
5. Click **Save**
6. Your site will be live at `https://<your-username>.github.io/<repo-name>/`

## 📁 Project Structure

```
├── index.html    # Main page structure
├── style.css     # Design system & all styles
├── data.js       # ⭐ Your portfolio content (edit this!)
├── app.js        # Rendering & interactions
├── assets/
│   └── resume.pdf  # Your downloadable resume
└── README.md
```
